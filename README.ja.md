## プロジェクト概要

GameFrameX の XLua コンポーネント - Lua コードの実行、Lua スクリプトの読み込み、Lua 環境の管理を行うインターフェースを提供します。

## インストール方法（いずれかを選択）

1. `manifest.json` の `dependencies` に追加：
   ```json
   {"com.gameframex.unity.xlua": "https://github.com/GameFrameX/com.gameframex.unity.xlua.git"}
   ```
2. Unity の Package Manager で Git URL を使用して追加
3. リポジトリをダウンロードして Unity プロジェクトの `Packages` ディレクトリに配置
