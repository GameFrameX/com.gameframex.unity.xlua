## 项目简介

GameFrameX 的 XLua 组件 - 提供了执行 Lua 代码、加载 Lua 脚本、管理 Lua 环境等操作的接口。

## 安装方式（任选其一）

1. 直接在 `manifest.json` 的文件中的 `dependencies` 节点下添加以下内容
   ```json
   {"com.gameframex.unity.xlua": "https://github.com/GameFrameX/com.gameframex.unity.xlua.git"}
   ```
2. 在 Unity 的 `Packages Manager` 中使用 `Git URL` 的方式添加库，地址为：https://github.com/GameFrameX/com.gameframex.unity.xlua.git
3. 直接下载仓库放置到 Unity 项目的 `Packages` 目录下。会自动加载识别
