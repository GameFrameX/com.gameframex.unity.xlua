## Project Overview

GameFrameX XLua Component - provides interfaces for executing Lua code, loading Lua scripts, and managing the Lua environment.

## Installation (choose one)

1. Add to `manifest.json` dependencies:
   ```json
   {"com.gameframex.unity.xlua": "https://github.com/GameFrameX/com.gameframex.unity.xlua.git"}
   ```
2. Add via Unity Package Manager using Git URL:
   https://github.com/GameFrameX/com.gameframex.unity.xlua.git
3. Download the repository and place it in your Unity project's `Packages` directory
