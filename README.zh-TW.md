## 項目簡介

GameFrameX 的 XLua 組件 - 提供了執行 Lua 代碼、加載 Lua 腳本、管理 Lua 環境等操作的接口。

## 安裝方式（任選其一）

1. 直接在 `manifest.json` 文件中的 `dependencies` 節點下添加
   ```json
   {"com.gameframex.unity.xlua": "https://github.com/GameFrameX/com.gameframex.unity.xlua.git"}
   ```
2. 在 Unity 的 `Packages Manager` 中使用 `Git URL` 添加
3. 直接下載倉庫放置到 Unity 項目的 `Packages` 目錄下
